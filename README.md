# Philosophy Resources

A personal reference library for studying Aristotelian and scholastic philosophy, with an emphasis on metaphysics, causality, teleology, and Aquinas. The collection brings together primary texts, scholarly works, introductory guides, and related contemporary discussions for reading and research.

## Collection

Resources are organized primarily by author or editor:

- [`edward_feser/`](edward_feser/) - Works by Edward Feser and related material on Aquinas, Aristotle, scholastic metaphysics, teleology, and natural philosophy.
- [`richard_hassing/`](richard_hassing/) - Material edited by Richard Hassing, including studies of final causality in nature and human affairs.

The library currently contains EPUB and PDF documents. Filenames are retained as supplied where possible so that the source title and author remain identifiable.

## Purpose

This repository is intended to support:

- focused reading in classical and scholastic philosophy;
- comparison between historical texts and contemporary interpretations; and
- building a searchable, author-organized reference collection over time.

## Adding resources

When expanding the collection, place each work in the directory of its principal author or editor. Create a new author directory when needed, and preserve useful bibliographic information in filenames. Avoid committing duplicate copies of the same work.
